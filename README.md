# timer
a linux cli timer made in c++



---------------------------
to install;
(in home dir)
```sh
git clone https://github.com/eon5942/timer
g++ -O2 -o timer timer.cpp
```
in shell config:
```sh
alias timer="~/timer"
```
-------------------------------
for hour (say 6 hours) do: 6h
for minute (say 48) do: 48m
for second (say 30) do: 30s
you can combine them like this 6h48m30s
run timer then how much time infront of that
for 5hours 6minutes and 30seconds do
```sh
timer 5h6h30s
```
